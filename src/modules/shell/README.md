# `shell/`: App chrome

Components here wrap the whole app and use `shell-*` tags, such as `shell-app`.

Use this namespace for:

- Root app bootstrap (`shell-app`).
- Global layout, theme, and docked panels.

For example, `app/` is the shell root; add sibling folders for other app chrome.

Put route views in `page/` and reusable widgets or SLDS blueprints in `ui/`.
